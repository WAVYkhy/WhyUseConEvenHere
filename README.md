# 여기서까지콘을써야겠냐

순정 Discord 클라이언트(클라이언트 변조/플러그인 설치 없음)에서 **아카콘(아카라이브)** 및 **디시콘(디시인사이드)** 을 빠르게 검색하고 `Ctrl+V`로 바로 붙여넣을 수 있는 **Windows 전용 Tauri v2 트레이/오버레이 앱**입니다.

## 주요 기능

- **전역 단축키 오버레이**: 기본 `Alt + E` 단축키로 현재 마우스 커서 위치에 오버레이 피커를 즉시 호출합니다. (설정에서 단축키 변경 가능)
- **순정 Discord 호환 (`CF_HDROP`)**: 선택한 이모티콘(움짤 GIF / WebP 변환 포함)을 Windows 파일 드롭 클립보드 형식으로 복사하여 Discord 채팅창에 `Ctrl+V`로 바로 첨부할 수 있습니다.
- **팩 관리**: 아카콘/디시콘 URL 또는 팩 ID를 입력해 팩을 추가하고, 최근 사용 / 즐겨찾기 / 이미지 리사이즈 옵션을 지원합니다.
- **시스템 트레이 & 자동 실행**: 백그라운드 트레이에 상주하며, Windows 시작 시 자동 실행 옵션을 제공합니다.

## 지원 환경

- **OS**: Windows 10 / 11 (x64) — Win32 `CF_HDROP` 클립보드 및 모니터/DPI API를 사용하므로 Windows 전용입니다.

## 설치 및 사용 방법

1. **Releases** 페이지에서 최신 설치 파일(`*-setup.exe` 또는 `*.msi`)을 다운로드해 실행합니다.
   - *참고: 코드 서명이 적용되지 않은 개인 빌드이므로 실행 시 Windows SmartScreen("Windows의 PC 보호") 경고가 표시될 수 있습니다. `추가 정보` → `실행`으로 진행할 수 있습니다.*
2. 앱 실행 후 시스템 트레이에 아이콘이 표시되면 `Alt + E`(또는 트레이 아이콘 클릭)로 피커를 엽니다.
3. `+` 탭에서 원하는 아카콘/디시콘 URL 또는 ID를 입력해 팩을 추가합니다.
4. 이모티콘을 클릭하면 클립보드에 복사되며, Discord 채팅창에서 `Ctrl + V`를 누르면 전송됩니다.

## 소스 코드에서 빌드하기

### 사전 요구 사항
- **Node.js** (v20 이상 권장) & **pnpm**
- **Rust** (`rustup`, `cargo`)
- **Visual Studio C++ Build Tools (MSVC)** 및 **Windows SDK**

### 빌드 명령어

```bash
# 의존성 설치
pnpm install

# 프론트엔드 및 코어 패키지 빌드
pnpm build

# Tauri 데스크톱 앱 개발 실행
pnpm dev:desktop

# Windows 인스톨러(.exe / .msi) 빌드
pnpm tauri:build
```

## 프로젝트 구조

- `packages/core` (`@discordcon/core`): 아카콘/디시콘 메타데이터 파싱, 미디어 변환(WebP/GIF), 캐싱 로직
- `apps/desktop` (`@discordcon/desktop`): Tauri v2 (Rust 백엔드 + React/Vite 프론트엔드) 트레이/오버레이 데스크톱 앱
